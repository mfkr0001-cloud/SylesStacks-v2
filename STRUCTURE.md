# Структура

- `index.html`, `css/style.css`, `js/app.js` — текущая рабочая версия v2.3.
- `js/core/`, `js/modules/`, `js/api/`, `js/components/` — модульная архитектура для дальнейшего переноса и расширения. Эти файлы пока не подключены к `index.html`.
- `assets/` — ресурсы интерфейса.
- `data/` — примеры начальных данных; текущая версия хранит пользовательские данные в localStorage.
- `android/` — только заготовка под будущий нативный проект, не готовый эмулятор.
- `tests/` — проверки небольших модульных помощников.
