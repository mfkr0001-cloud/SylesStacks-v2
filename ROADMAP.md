# План развития

1. Проверить текущую веб-версию и сохранить совместимость данных v2.1/v2.2/v2.3.
2. Поэтапно переносить функции из `js/app.js` в `js/core/`, `js/modules/` и `js/components/`.
3. Подключить и проверить API отдельного Render-сервера.
4. Отдельно проектировать нативное Android-приложение и runtime.
5. Не заявлять запуск APK, системный FPS, GMS или overlay до реальной реализации и тестирования.
