# API

Фронтенд рассчитан на отдельный backend. В `js/core/config.js` задаётся `apiBaseUrl`. В `js/api/` подготовлены клиентские вызовы конфигурации и выхода. Реальные маршруты, проверка Google credential и сессии должны быть реализованы и проверены на отдельном сервере. Секреты (`SESSION_SECRET`, OAuth client secret) нельзя помещать во фронтенд.
