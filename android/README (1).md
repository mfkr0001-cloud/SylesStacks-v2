# Android-модуль — заготовка

Здесь пока нет APK, Android VM, Android runtime или Google Mobile Services. Подпапки оставлены для будущей нативной разработки. Для настоящей реализации понадобятся Android-проект, сборочная система, совместимый runtime и отдельная проверка лицензирования GMS. Веб-интерфейс сам по себе не запускает APK.
