# SylesStacks v2

Веб-приложение SylesStacks для управления библиотекой игр,
настройками и производительностью.

## Запуск
Открой index.html в браузере.

## Структура
- css/ — стили
- js/ — JavaScript
- data/ — данные
- docs/ — документация
- tests/ — тесты
- android/ — информация об Android-версии
- legacy/ — старые файлы
