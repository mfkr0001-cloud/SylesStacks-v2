# SylesStacks v2.3

Проект разделён на клиентский веб-интерфейс и подготовленные папки для будущего развития.

## Что уже работает в этой версии
- Веб-интерфейс и навигация.
- Библиотека игр и игровые профили в localStorage.
- Настройки и экспорт/импорт JSON.
- Предпросмотр и профили прицела внутри страницы.
- Диагностика данных, доступных браузеру.

## Структура
Подробности — в `docs/STRUCTURE.md` и `docs/ROADMAP.md`.

## Запуск
Открой `index.html` или опубликуй папку как статический сайт (например, GitHub Pages).

## Отдельный сервер
Backend не включён в этот архив. Он остаётся в отдельном GitHub-репозитории и на Render: `https://server-5aky.onrender.com`. Укажи его адрес в `js/core/config.js`, когда будешь подключать модульные API-вызовы. Серверные секреты нельзя помещать в этот проект.

## Важно
Папка `android/` — заготовка, а не готовая Android-среда. Этот веб-проект не запускает APK, не предоставляет системные Google Mobile Services и не меняет системный FPS телефона. Файлы в `js/core/`, `js/modules/`, `js/api/` и `js/components/` подготовлены для постепенного переноса; текущая рабочая логика остаётся в `js/app.js`.
