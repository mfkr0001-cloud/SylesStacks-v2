# JavaScript

`app.js` — единственный подключённый сейчас скрипт v2.3; он содержит рабочую логику существующего интерфейса.

Подпапки `core/`, `modules/`, `api/` и `components/` — подготовленная архитектура для постепенного переноса кода. Их файлы пока не подключены к странице, чтобы не сломать текущую сборку.
